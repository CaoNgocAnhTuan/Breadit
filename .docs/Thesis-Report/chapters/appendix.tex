\section*{Appendix A. Full test list}
\addcontentsline{toc}{section}{Appendix A. Full test list}

This appendix lists every test suite of the project, with its file and its number of tests, grouped by level. The counts are those of 2026-11-22, and they equal the totals of Table~\ref{tab:test-levels} in Chapter 8. A suite is one test file. A suite with 5 tests or fewer also lists its tests; for the others, the last column says what the suite covers. The letters and numbers in brackets (T1, S5, N4 and so on) are IDs of the Bugs Report of the project: the problem that the suite guards.

Chapter 6 shows eleven tables of the results report (tuning, test users and left-out users, E1 to E8, and the groups of the Orientation) in full, so this appendix does not repeat them. Table~\ref{tab:results-e2} shows family F1 at $K = 10$ only, and family F2 has no table in Chapter 6.

The rows are read from the result file \texttt{.docs/results/p7-main/compare.csv} when the thesis is built, with six decimals as in the file. The file is listed with its SHA-256 in the manifest of the run \texttt{p7-main}, a Class D result, so every value is the same on every rebuild (Chapter 3). The columns are:
\begin{itemize}
  \item \textbf{Group.} The history group (Chapter 3). The group ``all'' holds every test user whose test post is in the pool (family F2 only).
  \item \textbf{Users.} The number of users in the group, after the left-out users are removed.
  \item \textbf{Gain.} The mean over users of NDCG@$K$ of $H$ minus NDCG@$K$ of the baseline in the first column. A negative gain means that the baseline is better.
  \item \textbf{CI low, CI high.} The paired bootstrap 95\% confidence interval of the gain.
  \item \textbf{$p$ and $p$ (Holm).} The $p$-value of the paired randomization test, and the same value after the Holm correction in its family on its dataset.
\end{itemize}
H1 is decided only for $K = 10$ and group 0--4 (Chapter 3). The rows for $K = 5$ and $K = 20$ are given for completeness and do not change that decision.
