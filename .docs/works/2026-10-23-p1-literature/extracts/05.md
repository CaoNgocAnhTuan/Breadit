Says:
RealGraph is a framework at Twitter that scores how strong each one-way tie between two users is. The score is the chance that the source user will interact with the destination user in the future. It is built with a logistic regression model trained on past interaction data. Twitter uses these weights for user recommendations, search ranking and similar-user discovery. The paper checks the model with AUC and a small user survey.

Answers:
Q1. Weight = probability, not a count. Abstract, page 1, line 15: "directed edge also has a weight that is the probability of any". Section 2, page 2, line 148: "the weight, i.e., the probability of future interactions on".

Q2. Data: edge features (page 2, Sec 2.1.1: visible and implicit interactions, time-series counts) plus vertex features of both users (Sec 2.1.2). Label: binary, page 3, line 272: "the training label for an edge is set to 1 or -1 depending". Model: logistic regression trained on the PigML pipeline (Sec 2.2, page 3, line 258: "We use the PigML pipeline at Twitter [6] to periodically"). Sec 3.1, page 4, line 368: "Using this data we train a model using stochastic". Line 369: "gradient descent logistic regression with L2 regularization".

Q3. Directed graph: yes. Page 1, line 12: "produces a directed and weighted graph where". The paper does not state in words that A-to-B and B-to-A get different weights. The features are per source user (page 2, line 216: "use it for the source user as sending"), which implies it, but this is my inference, not the paper's claim.

Q4. Not found: no smoothing or prior for users with few interactions. The only regularization is global L2 in the model (page 4, line 369, quoted in Q2), not a per-user prior. Page 2, footnote 2 (line 220) is about decay: "When this value becomes too small for an interaction type," the feature is removed. This is removal, not smoothing.

Q5. Use: Twitter applications, Sec 2.3 (page 3, line 300: "the Circle of Trust"), and Who To Follow (page 2, line 106: "Who To Follow [5]"). Evaluation: (i) AUC per feature group, Sec 3.1, Table 1 (0.830 to 0.877, page 4). (ii) Survey of top-20 followings, Sec 3.2, page 4, line 417: "So overall people found than 82% of Twitter followers". The paper calls this "a preliminary result" (page 4).

Not found:
- Any smoothing, prior or back-off for users with few interactions (searched: smooth, prior, Laplace, shrink, sparse, cold, backoff).
- An explicit statement that A-to-B and B-to-A weights differ.
- The venue "KDD" for this workshop paper.
- A paper version number.
- Numeric gains for search, typeahead or click rate; the paper says only "improvements in click rate" (page 3).
