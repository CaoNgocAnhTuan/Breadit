Says:
The home-mixer code reads a real-graph score for each (viewer, candidate author) pair from a Manhattan store keyed by the viewer ID. The hydrator sorts these scores, keeps the top 1000, and rescales them from the 0 to 1 range to the v1 range. It then puts the map into a feature called RealGraphInNetworkScoresFeature. A second hydrator loads RealGraph edge features per viewer from a user-session store. The code I read does not show any ranking weight that uses these features.
The cr-mixer code uses In-Network RealGraph as a candidate source for user recommendations, as far as the file shows.
The file that sets the in-network flag for tweets (InNetworkFeatureHydrator) uses the follow list and the viewer's own ID, and does not read RealGraph.
